# Digital Forensics Investigation

## Overview
This project involves a forensic investigation of a USB drive to uncover hidden and deleted evidence.

## Objectives
- Maintain proper chain of custody
- Recover deleted and hidden files
- Analyze metadata and encrypted data

## Tools Used
- FTK Imager
- Autopsy
- Hashing tools (MD5, SHA-1)

## Key Findings
- Recovered deleted files from the USB drive
- Extracted metadata from image files
- Identified hidden information used to decrypt protected files
- Verified evidence integrity using hash values

## Skills Demonstrated
- Digital forensics analysis
- Evidence handling and chain of custody
- Data recovery and investigation
